# Formula Navigator

C#-надстройка для Excel 64-бит под Windows: дерево формулы с точной подсветкой выбранного выражения, переходы к исходным ячейкам и поиск зависимых ячеек между листами.

- `Ctrl+Q` — формула, исходные ссылки, вычисленные адреса `OFFSET` / `INDIRECT`.
- Листья дерева — ссылки текущей формулы; числа, строки и ветки без ссылок не создают отдельных узлов. Исходный текст и точная подсветка сохранены.
- `Ctrl+Shift+Q` — прямые зависимые ячейки по всей текущей книге. Книги заранее индексируются, повторные запросы используют общий индекс диапазонов.
- `Enter` на ссылке или результате поиска — перейти в Excel и закрыть окно; `Ctrl+Enter` — разобрать формулу ссылки.
- Окна шириной 390 / 360 единиц Windows открываются у правого края Excel. Фокус при открытии в дереве, стрелки для узлов, `Tab` / `Shift+Tab` для элементов окна.
- Пока окно открыто, клавиатура работает в надстройке; `Enter` / `Esc` возвращают управление листу. Предпросмотр ссылок меняет выделение Excel за окном.
- C# + Excel-DNA 1.9 + .NET Framework 4.8 + WPF; результат — `.xll`.
- Полная сборка предусмотрена в Linux-контейнере; на Windows нужен только запуск надстройки.

```bash
bash tools/build-in-docker.sh
```

Скрипт использует Buildx, если он установлен, иначе — обычный `docker build` и `docker cp`. После успешной сборки готовый файл появится в `artifacts/FormulaNavigator64.xll`.

Каждый `push` в ветку `main` (включая слияние PR) запускает ту же Docker-сборку и публикует `FormulaNavigator64.xll` в отдельном GitHub Release с возрастающим тегом `v0.0.<номер запуска workflow>`. В описании релиза указаны полный SHA со ссылкой на коммит и его заголовок. Повторный запуск использует тот же тег. Push в другие ветки и теги релиз не запускает. Публикация повторяет временные ошибки GitHub API до трёх раз.

Подробные требования, подключение, проверки и ограничения: **[BUILD_AND_INSTALL.md](BUILD_AND_INSTALL.md)**.

Версия 1.0.5: предварительная индексация зависимых ячеек, обновление после правок и пересчёта, статический расчёт `OFFSET` с постоянными смещениями, исправление ссылок `I$140` и чтения широких блоков. Docker-сборка запускает 20 групп C#-тестов, собирает надстройку и проверяет формат x64, экспорт `xlAutoOpen` и отсутствие отдельной зависимости от Office Interop DLL. Работа событий, фоновой индексации, окон и фокуса требует проверки в Windows Excel. Инструменты .NET используются внутри Docker.

После изменения книги индекс целиком перестраивается с задержкой 750 мс. Вычисляемые ссылки повторно разрешаются после изменения данных или пересчёта. Первое построение и книги с большим числом таких ссылок всё ещё могут требовать ожидания; время поиска показывается в окне. «Обновить» принудительно перечитывает книгу. После макросов, которые меняли её при отключённых событиях Excel, нажми эту кнопку.
